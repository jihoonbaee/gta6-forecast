Forecasts GTA VI's launch-day Twitch concurrent viewers hour by hour (hours 2–24) as five quantiles, fitted at run time from past game-launch comparables: per-hour OLS on log hour-1 viewers, a rolling-midnight median floor, and honest residual spreads. Practice mean pinball loss 0.194 vs house baseline 0.387.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
